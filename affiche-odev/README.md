# Affiches ODev — Canva

Deux visuels prêts à l'emploi pour présenter **ODev** et ses services.

## Fichiers

| Fichier | Format | Usage recommandé |
|---------|--------|------------------|
| `export/ODev-Affiche-Portrait.png` | Portrait 3:4 | Affiche A4, story Instagram, LinkedIn |
| `export/ODev-Affiche-Landscape.png` | Paysage 16:9 | Bannière web, présentation, écran |

## Importer dans Canva

1. Ouvrir [canva.com](https://www.canva.com) → **Créer un design**.
2. Choisir le format adapté :
   - **Affiche (A4)** ou **Story Instagram** pour le portrait
   - **Présentation (16:9)** ou **Bannière LinkedIn** pour le paysage
3. **Importer** → glisser le PNG depuis `export/`.
4. Ajuster si besoin (texte, QR code, logo) — le visuel est déjà complet.

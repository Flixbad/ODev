# Export diapositives — ODev

Génère un fichier **PowerPoint (`.pptx`)** du dossier de création, importable dans **Canva** et **Google Slides**.

## Générer le fichier

```bash
cd dossier-creation
npm install
npm run slides
```

Le fichier est créé ici :

```
dossier-creation/export/ODev-Dossier-Creation.pptx
```

## Importer dans Canva

1. Va sur [canva.com](https://www.canva.com)
2. **Créer une conception** → **Importer un fichier**
3. Sélectionne `ODev-Dossier-Creation.pptx`
4. Canva convertit les diapositives — tu peux ensuite retoucher textes, couleurs, images

## Importer dans Google Slides

1. Va sur [Google Slides](https://slides.google.com) → **Présentation vierge**
2. Menu **Fichier** → **Importer des diapositives**
3. Onglet **Upload** → envoie `ODev-Dossier-Creation.pptx`
4. Sélectionne toutes les diapos → **Importer**

Astuce alternative Google Drive : uploade le `.pptx` sur Drive → clic droit → **Ouvrir avec** → **Google Slides**.

## Contenu des slides

1. Couverture  
2. Identité  
3. Motivation (constat / réponse)  
4. Principes  
5. Offre de services  
6. Marché & impact  
7. Modèle & porteur  
8. Demande d'ouverture  

Aucune mention RP — document cohérent pour une présentation institutionnelle.

# Dossier de création — ODev

Document de présentation HTML pour l'ouverture de la micro-entreprise **ODev** (Darren O'Sullivan).

## Contenu

1. Identité
2. Motivation / pourquoi ouvrir
3. Offre (sites, React, Node.js, gestion d'entreprise…)
4. Marché & impact
5. Modèle économique
6. Porteur de projet
7. Demande formelle

## Ouvrir

Ouvre `index.html` dans un navigateur, ou sers le dossier :

```bash
npx serve dossier-creation
```

Bouton **Imprimer / PDF** en haut à droite pour générer un PDF via le navigateur.

## Export Canva / Google Slides

```bash
cd dossier-creation
npm install
npm run slides
```

→ fichier `export/ODev-Dossier-Creation.pptx`  
Guide : [EXPORT-SLIDES.md](./EXPORT-SLIDES.md)

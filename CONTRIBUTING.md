# Contribuer à ODev

Merci de contribuer à ce projet de démonstration.

## Prérequis

- Node.js 20+
- npm 10+

## Setup local

```bash
npm install
npm run dev
```

## Bonnes pratiques

- Une PR = un sujet clair
- Respecter le design system (variables CSS dans `globals.css`)
- Préférer des composants ciblés dans `src/components`
- Tester le responsive (mobile / desktop)
- Respecter `prefers-reduced-motion`

## Style de commits

Utiliser des messages conventionnels :

- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `refactor:` refactorisation
- `docs:` documentation
- `style:` mise en forme
- `test:` tests
- `chore:` maintenance
